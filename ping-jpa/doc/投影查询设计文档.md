### AST 设计

#### select

```json5

{
  "field_alias": "字段别名",
  "entity_alias": "实体别名",
  "field": "字段名称"
}

```

#### from

```json5

{
  "entity_name": "实体名称",
  "alias": "别名"
}

```

#### join

```json5
{
  "main_alias": "主表别名",
  "current_alias": "从表别名",
  "type": "inner|left|right",
  "main_join_name": "主表关联字段名称",
  "current_join_name": "从表关联字段名"
}
```

#### where

```json5
{
  "main_alias": "主表别名",
  "current_alias": "从表别名",
  "type": "equal|like|...",
  "main_join_name": "主表关联字段名称",
  "current_join_name": "从表关联字段名"
}
```

