# 阶段 3 设计：语义一致与验收

对应 `tasks.md` 阶段 3（任务 3.1–3.3）。架构决策见 `../design.md` D10（web 部分）。

> 注：本文档待细化，当前只固定对照测试的方式与文档要求。

## 对照测试

同一套 box 在两种形态下必须产生相同的渲染状态：

| 对象类型（实现约定） | 终端交互形态 | web 形态 |
|---|---|---|
| `user` / `text` | rpc → lua 行缓冲 | WS frame |
| `tool` | 工具卡片 | WS frame |
| `confirm` | 确认框 + 上行命令 | WS 双向 |
| `error` | 错误行 | WS frame |

测试方式：对同一组 box 序列，分别经两个消费端处理，断言：

- 对象按 `id` 归组后的内容一致；
- 结束判定一致（`seq` 非负以外即结束）；
- 缺口恢复行为一致（`pull(from_id)` 后状态一致）。

## 文档要求
