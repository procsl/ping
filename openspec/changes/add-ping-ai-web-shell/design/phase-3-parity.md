## 对照测试

同一事件类型在两种形态下必须表达相同的含义：

| 事件 | 终端交互形态 | web 形态 |
|---|---|---|
| `message.delta` | rpc 通知 → lua 行缓冲 | WS frame |
| `tool.requested` | 界面卡片 | WS frame |
| `tool.confirm` | rpc 请求 → 确认框 → 回响应 | WS 双向请求/响应 |
| `message.completed` | 行缓冲收尾 | WS frame |
| `error` | 界面错误行 | WS frame |

测试方式：对同一组事件，分别经两个适配器编码，断言解码后的事件类型与关键字段一致。
