# Spec Delta

## Purpose

把 agent 的核心能力以一次性命令行调用的形式交付：给定角色与提示词，流式写标准输出后退出，不建立任何网络监听。

## ADDED Requirements

### Requirement: 非交互式单次问答
非交互式调用 SHALL 接收一个用户提示词，把增量产出写到标准输出，并在完成后退出。

#### Scenario: 正常问答
- **WHEN** 以用户提示词调用非交互式形态
- **THEN** 增量输出到标准输出并以成功状态退出

#### Scenario: 未提供提示词
- **WHEN** 调用时没有提供提示词且角色提供了默认用户提示词
- **THEN** 以默认用户提示词发起对话

### Requirement: 命令行参数风格
命令行参数 SHALL 使用长参数形式，SHALL NOT 要求使用者记忆短参数。

#### Scenario: 指定角色与工具
- **WHEN** 以长参数形式指定角色与工具子集
- **THEN** 参数被解析并生效

#### Scenario: 非法参数值
- **WHEN** 参数值不合法（未知角色、未知工具名、非法会话标识）
- **THEN** 输出明确错误信息并以非零状态退出

### Requirement: 消费完成对象
非交互式形态 SHALL 通过提交返回的完成对象消费本轮的 box，SHALL NOT 自行实现重放、确认或断线恢复。

#### Scenario: 等待本轮结束
- **WHEN** 提交后消费完成对象
- **THEN** 本轮全部 box 被渲染，等待在轮次结束时返回

#### Scenario: 不实现重放
- **WHEN** 非交互式形态运行
- **THEN** 不发送确认、不请求重放，也不处理断线

### Requirement: 按对象渲染
非交互式形态 SHALL 按对象 `id` 升序渲染收到的 box；用户消息与助手文本 SHALL 写入标准输出，错误对象 SHALL 写入标准错误。

#### Scenario: 用户消息与助手文本
- **WHEN** 收到用户消息对象与助手文本对象
- **THEN** 按 `id` 升序把内容写入标准输出

#### Scenario: 错误对象
- **WHEN** 收到错误对象
- **THEN** 把错误内容写入标准错误并以非零状态退出

#### Scenario: 不支持的对象类型
- **WHEN** 收到本形态不渲染的对象类型
- **THEN** 忽略该对象，不影响其余输出

### Requirement: 输出可接入管道
标准输出 SHALL NOT 包含交互式界面所需的控制序列，以便接入管道与重定向。

#### Scenario: 接入管道
- **WHEN** 其标准输出接入管道
- **THEN** 输出不包含光标控制、清屏或颜色控制序列

### Requirement: 终端形态不监听端口
非交互式形态 SHALL NOT 监听任何网络端口。

#### Scenario: 普通启动
- **WHEN** 以非交互式形态运行
- **THEN** 进程不建立任何网络监听

### Requirement: 独立运行默认不启动 web
模块单独打包运行时 SHALL 以终端程序形态运行，除非显式要求 web 形态。

#### Scenario: 单独打包运行
- **WHEN** 单独作为终端程序运行且未指定 web 形态
- **THEN** 不启动 web 服务

### Requirement: 可执行交付物
模块 SHALL 能产出可直接运行的可执行 jar，且该 jar 不依赖外部数据库。

#### Scenario: 打包后运行
- **WHEN** 执行打包并直接运行产物
- **THEN** 程序正常启动、不连接数据库、不监听端口

### Requirement: 退出状态
非交互式形态 SHALL 在成功完成时以 0 退出，在无法完成时以非零退出。

#### Scenario: 成功完成
- **WHEN** 一次问答正常结束
- **THEN** 退出状态为 0

#### Scenario: 无法完成
- **WHEN** 配置不可读、角色不存在或模型调用失败
- **THEN** 退出状态非零且错误信息可读
